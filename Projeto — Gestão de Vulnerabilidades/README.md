# Gestão de Vulnerabilidades com Excel

Projeto desenvolvido para aplicar conhecimentos de Excel em um cenário de Cybersecurity / Vulnerability Management.

## 🎯 Objetivo

Analisar uma base de 600 vulnerabilidades e identificar onde está concentrado o maior risco e quais vulnerabilidades devem ser priorizadas.

## 🛠️ Ferramentas

- Microsoft Excel
- Tabelas Dinâmicas
- Fórmulas
- Risk Score
- Dashboard

## 📊 Projeto

O projeto utiliza um dataset **100% sintético** com 600 registros de vulnerabilidades.

A análise considera fatores como:

- CVSS
- EPSS
- CISA KEV
- Exposição à internet
- Ambiente
- Status

Foi desenvolvido um modelo de Risk Score e uma classificação de prioridade para as vulnerabilidades abertas.

## 📁 Arquivos

- `Cybersecurity_Excel_Lab_Vulnerability_Management.xlsx` → projeto desenvolvido no Excel
- `Documentacao_Projeto_Gestao_de_Vulnerabilidades.pdf` → documentação completa do projeto

## 🔎 Resultado

O maior Risk Score encontrado foi **15**, e **12 vulnerabilidades** foram classificadas como Priority 1.
