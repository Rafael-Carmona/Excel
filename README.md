# 📊 Projetos em Excel

Este repositório reúne meus projetos desenvolvidos **exclusivamente com Microsoft Excel**.

A ideia é aplicar, na prática, os conhecimentos que venho desenvolvendo em Excel por meio de projetos próprios, explorando análise de dados, fórmulas, Tabelas Dinâmicas, dashboards e outras ferramentas da plataforma.

## 🎯 Objetivo

Criar projetos práticos para desenvolver e demonstrar minha evolução em Excel, sempre utilizando o próprio Excel como principal ferramenta de construção e análise.

## 📁 Projetos

Cada pasta deste repositório representa um projeto independente, contendo seus respectivos arquivos, documentação e resultados.

## 🛠️ Ferramenta

- Microsoft Excel

## 📈 Evolução

Este repositório será atualizado conforme novos projetos forem desenvolvidos, acompanhando minha evolução desde projetos mais simples até análises mais completas e avançadas.

---

**Todos os projetos deste repositório foram desenvolvidos utilizando exclusivamente o Excel.**
